# APIメニュー

## Manage Clients...

**API → Manage Clients...** は、HTTP API（`X-API-Key`ヘッダー）で装置を操作できる
クライアント（連携アプリケーション）の一覧を管理します。

キーはクライアントごとに1つ発行されるため、**片方のクライアントだけを失効させる**ことができ、
どのクライアントが最後にいつリクエストを送ってきたかも確認できます。

ダイアログでできること:

- **Add… / Rename… / Allowed IPs…**: クライアントの追加、名前の変更、許可する要求元アドレスの設定。
- **Reveal key / Copy key**: マスク表示されているキーの表示とコピー。
- **Regenerate key**: そのクライアントのキーだけを再発行します（他のクライアントには影響しません）。
- **Revoke**: そのクライアントを削除します。

**Save** を押した時点で反映され、APIサーバーの再起動は不要です（次のリクエストから有効）。
更新前の古いキーで届いたリクエストは `401 Unauthorized` になるため、
連携クライアント側の設定も併せて更新してください。

キーの保存場所、許可IPの書き方、旧バージョンの単一キーファイルからの自動移行については
[クライアントと認証](../../api/clients.md)を参照してください。
APIサーバーの動作モード全体については[API連携](../../api/index.md)を参照してください。
