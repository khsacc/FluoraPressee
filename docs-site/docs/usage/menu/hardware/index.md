# Hardwareメニュー

装置そのものの設定・状態・保存済み測定条件を扱う3つのダイアログを開きます。

| 項目 | 開くダイアログ | 用途 |
|---|---|---|
| [Hardware Configuration...](hardware-configuration.md) | 設定編集 | `spectrometerConfig.json`をGUI上で編集する |
| [Instrument Status...](instrument-status.md) | 状態表示（読み取り専用） | カメラ・分光器の現在の状態を診断する |
| [Manage Configuration Files...](manage-configuration-files.md) | 一覧・削除 | 保存済みConfigurationレコードを機種を問わず一覧・削除する |

いずれも独立したダイアログとして開き、メイン画面の測定・表示操作とは別に確認できます（Hardware Configuration...を除く）。
